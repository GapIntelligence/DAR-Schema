# Contributing to DAR Schema

Thank you for taking the time to contribute! We welcome issues and pull requests from the community.

## How to Contribute

1. **Fork the repository** on GitHub and clone your fork locally.
2. **Create a new branch** for your work:
   ```bash
   git checkout -b my-feature
   ```
3. **Make your changes** and commit them with clear messages.
4. **Run the tests** to ensure everything still works:
   ```bash
   pytest
   ```
5. **Open a pull request** against the `main` branch and describe your changes.

## Reporting Issues

If you encounter a bug or have a feature request, please open an issue. Include as much detail as possible so we can understand and reproduce the problem.

## Documentation Improvements

Updates to the documentation are always appreciated. The documentation lives in the `docs/` directory. Feel free to submit corrections or improvements alongside code changes or as separate pull requests.

We appreciate your help in improving DAR Schema!
