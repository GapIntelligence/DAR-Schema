# DAR Schema Documentation

Welcome to the documentation for **DAR Schema** (Data Archive Request). This site provides resources for installing, using and understanding the DAR format and tools.

## Available Guides

- **[Getting Started](getting-started.md)** – Step-by-step instructions for installing the tools and creating your first DAR file.
- **[Comparison with HAR](comparison-with-HAR.md)** – Details on how DAR extends the traditional HAR format and the benefits it offers.
- **[Usage Examples](usage-examples.md)** – Practical examples showing how to convert, parse and analyze DAR files.
- **[Specification](../SPEC.md)** – The full technical specification of the DAR file format.

## Additional Resources

Refer to the [README](../README.md) for an overview of the project, or see the `tools/` directory for scripts that work with DAR files.

We hope these documents help you get the most out of the DAR Schema project. If something is missing or unclear, please [open an issue](https://github.com/OpenBrand/DAR-Schema/issues) or submit a pull request.
